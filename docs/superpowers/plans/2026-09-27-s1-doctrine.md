# S1 Doctrine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every Voxren Pi system prompt carries the full coaching doctrine (basics and mastery rows with stable ids) migrated from `voxren/prompts/`, validated at load and under a 32 KB prompt cap.

**Architecture:** A new top-level `doctrine:` key in `coach.yaml` holds `basics` and `mastery` lists of `{ id, rule }`. `validateCoachYaml` in `src/contracts.ts` enforces the id and rule contract; `coachSystemPrompt` appends the rendered rows (labels from `prompts`, ids never rendered) after `prompts.system` and before the per-launch rows. Content lands in two reviewable tasks, basics then mastery.

**Tech Stack:** TypeScript on Bun (`bun test`), `yaml` parser, Pi extension (`coach -p` print mode).

**Spec:** `docs/superpowers/specs/2026-09-27-coach-knowledge-design.md` (section "S1 Doctrine").

## Global Constraints

- Prompt text lives only in `coach.yaml` (AGENTS rule 1). No rule, label, or template string in a `.ts` file.
- No champion or item names in doctrine (AGENTS rule 5, spec migration edit 1).
- Doctrine id pattern: `^[a-z]+(\.[a-z0-9-]+)+$`, unique across both layers.
- Doctrine groups (first id segment): `prime`, `role`, `lane`, `wave`, `trade`, `tempo`, `macro`, `vision`, `objective`, `jungle`, `fight`, `build`, `comp`, `state`, `soloq`, `mental`, `calibration`, `craft`.
- A rule is one non-empty line.
- System prompt size cap: under 32 KB (32768 bytes) with every launch option on.
- Tests prove behavior through public functions; never grep a source file (AGENTS rule 6).
- Commits: stage paths explicitly with `git add <paths>`, never `git commit -am`. No co-author trailer.
- Work in the worktree `<worktree>`, branch `coach-knowledge-spec`.

## Review Focus

1. A rule with a YAML-special character (`: `, ` #`) left unquoted is silently truncated at load. Every rule is double-quoted, and Task 3 adds a test that every loaded rule ends in a period, which fails on truncation.
2. A rule containing `{{name}}` (an autoresearch edit expecting templating) would reach the model as literal braces. Task 2 adds a test that no loaded rule contains `{{`.
3. Doctrine growth (Task 3, Task 4, later autoresearch) pushes the prompt past the cap. Task 2 adds the size gate test, which Tasks 3 and 4 then run.
4. Doctrine ids leaking into the prompt waste tokens and invite the model to cite slugs. Task 2 adds a test that no id appears in the assembled prompt.
5. A doctrine rule that fights `prompts.system` format (for example the rule-to-keep row against "no closing line") makes answers fail the `has_intro_or_closing` rubric. No unit test can hold this; Task 5 reads real answers before and after and runs the answer rubric lab when `TYPESAFE_API_KEY` is set.

- [ ] **Step 3: Implement the contract**

In `src/contracts.ts`, above `export interface CoachYaml`, add:
```ts
/** One coaching rule; the id is stable across rewordings so judge questions and autoresearch diffs can cite it. */
export interface DoctrineRow {
	id: string;
	rule: string;
}

const DOCTRINE_ID = /^[a-z]+(\.[a-z0-9-]+)+$/;
const DOCTRINE_GROUPS = new Set(["prime", "role", "lane", "wave", "trade", "tempo", "macro", "vision", "objective", "jungle", "fight", "build", "comp", "state", "soloq", "mental", "calibration", "craft"]);
```
In `interface CoachYaml`, after `jev: {...};` add:
```ts
	/** Coaching doctrine rendered into the system prompt: basics first, then mastery. */
	doctrine: { basics: DoctrineRow[]; mastery: DoctrineRow[] };
```
In `validateCoachYaml`, immediately before `return yaml as CoachYaml;`, add:
```ts
	const doctrine = root.doctrine as Record<string, unknown> | undefined;
	assertPath(doctrine && typeof doctrine === "object", "doctrine");
	const seenIds = new Set<string>();
	for (const layer of ["basics", "mastery"]) {
		const rows = doctrine?.[layer];
		assertPath(Array.isArray(rows) && rows.length > 0, `doctrine.${layer}`);
		(rows as unknown[]).forEach((row, index) => {
			const path = `doctrine.${layer}[${index}]`;
			const entry = row as Record<string, unknown> | undefined;
			assertPath(entry && typeof entry === "object", path);
			const id = entry?.id;
			if (typeof id !== "string" || !DOCTRINE_ID.test(id)) throw new Error(`coach.yaml: ${path}.id must be a dotted slug like prime.death-cost (got ${JSON.stringify(id)})`);
			const group = id.split(".")[0];
			if (!DOCTRINE_GROUPS.has(group)) throw new Error(`coach.yaml: ${path}.id has unknown doctrine group "${group}"`);
			if (seenIds.has(id)) throw new Error(`coach.yaml: duplicate doctrine id ${id} at ${path}`);
			seenIds.add(id);
			assertPath(isNonEmptyString(entry?.rule) && !String(entry?.rule).includes("\n"), `${path}.rule`);
		});
	}
```
